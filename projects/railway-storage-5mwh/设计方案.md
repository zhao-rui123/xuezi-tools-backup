# 5MWh电气化铁路储能系统方案

## 一、系统概述

| 项目 | 参数 |
|------|------|
| 总容量 | 5 MWh |
| 电池类型 | 磷酸铁锂 |
| 电芯规格 | 3.2V / 314Ah |
| 直流母线电压 | 1500V（中间直流母线） |
| 接入电压 | 27kV直流（牵引网） |
| 预期用途 | 再生制动能量回收、削峰填谷 |

## 五、系统配置

### 5.1 配置计算

| 参数 | 计算 | 结果 |
|------|------|------|
| 单簇能量 | 9模组 × 52.2kWh | 469.8 kWh |
| 系统目标 | 5 MWh | 5000 kWh |
| **需要簇数** | 5000 / 469.8 | **10.67 → 11簇** |
| **实际容量** | 11 × 469.8 | **5167.8 kWh ≈ 5.17 MWh** |

### 5.2 最终配置

| 项目 | 数量 | 说明 |
|------|------|------|
| 电池模组 | 99个 | 11簇 × 9模组/簇 |
| 电芯总数 | 5148个 | 99模组 × 52S |
| 总能量 | 5.17 MWh | 超出目标3.4% |
| 直流母线电压 | 1498V | 接近1500V标准 |

## 六、DC-DC接口设计（适配27kV牵引网）

### 6.1 技术要求

| 参数 | 值 |
|------|-----|
| 输入电压 | ~1500V直流 |
| 输出电压 | 27kV直流 |
| 额定功率 | 5 MW |
| 效率 | ≥96% |
| 拓扑选择 | 链式H桥多电平 或 MMC |

### 6.2 27kV接入方案

```
电池系统 ── DC-DC (1500V→27kV) ── 27kV直流牵引网
                │
             监控保护
```

### 6.3 模块化DC-DC设计

- 采用模块化设计，便于维护和扩容
- N+1冗余配置，提高可靠性
- 响应时间 < 100ms（匹配再生制动特性）
