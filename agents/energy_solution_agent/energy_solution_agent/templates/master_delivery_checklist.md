# 行业大师级交付清单

> 用于在正式交付给业主/投委会前，快速确认输入、模型、输出三层是否完整。

## 1. 项目信息
- [ ] 项目名称、场景类型、坐标已确认
- [ ] 并网/离网模式已确认
- [ ] 目标优先级（IRR / NPV / coverage / reliability）已确认

## 2. 资源数据
- [ ] 使用了自动抓取（NASA POWER / Open-Meteo）或专业导入（8760）
- [ ] 光伏资源来源已记录
- [ ] 风资源来源已记录
- [ ] 若使用8760，已确认序列长度 = 8760
- [ ] 若使用风速序列，已确认 hub_height / shear_exponent / turbine_model

## 3. 负荷与时序
- [ ] 年总电量/峰值负荷已确认
- [ ] 是否提供了工作日/周末日型
- [ ] 是否提供了季节性日型
- [ ] 冷/热负荷是否有独立时序

## 4. 设备假设
- [ ] 光伏组件模型已确认
- [ ] 风机模型已确认
- [ ] 储能候选容量区间已确认
- [ ] SOC 约束 / 循环寿命 / 衰减率已确认

## 5. 市场与财务
- [ ] 外购电 / 柴油替代电价已确认
- [ ] 是否启用中国税法已显式确认
- [ ] 海外项目是否 `is_overseas_project=true`
- [ ] 融资结构（贷款/租赁/第三方）已确认
- [ ] 优化目标（irr/npv）已确认

## 6. 输出结果
- [ ] 系统 LCOE / LCOS 已输出
- [ ] 光伏 LCOE / 风电 LCOE / 储能 LCOS 已输出
- [ ] 收益拆解为金额，而非标签
- [ ] 基线年能源成本已输出
- [ ] 自行消纳率已输出
- [ ] 储能循环预警已检查
- [ ] 敏感性分析已真实重跑
- [ ] Word 报告可正常生成

## 7. 结论层
- [ ] 是否清楚说明“为什么是这个最优方案”
- [ ] 是否说明了前提边界（资源、税法、燃料价格、负荷曲线）
- [ ] 是否说明了主要风险点
