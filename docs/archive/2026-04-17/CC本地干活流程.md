# Claude Code 本地开发协作流程

## 整体架构

```
雪子（用户）
    ↓ 发出需求
主Agent（我 - 云端OpenClaw）
    ↓ 调度分配
本地Claude Code（笔记本CC）
    ↓ 执行开发
返回结果 → 主Agent → 汇报给雪子
```

## 双Agent协作模式

| 角色 | 工具 | 职责 |
|------|------|------|
| **主Agent**（云端） | OpenClaw | 架构设计、任务分配、结果汇总、飞书通知 |
| **执行Agent**（本地） | Claude Code | 实际代码开发、打包测试 |

## 工作流程

```
1️⃣ 雪子提出需求
         ↓
2️⃣ 主Agent分析需求
         ↓
3️⃣ 官方模型出架构设计（复杂项目）
         ↓
4️⃣ 主Agent拆解任务模块
         ↓
5️⃣ 启动本地CC执行各模块
         ↓
6️⃣ 本地CC完成 → 自动通知主Agent
         ↓
7️⃣ 主Agent汇总结果 → 飞书通知雪子
```

## 本地CC使用方式

### 方式1：Claude Code对话界面（推荐新手）

直接打开 Claude Code，在对话中粘贴需求描述即可。

### 方式2：命令行模式（快速任务）

```bash
# 直接执行简单任务
claude --print "帮我写一个Python脚本实现..."

# 指定项目目录
claude --print --cwd /path/to/project "帮我修改这个文件..."

# 使用插件能力
claude --print --dangerously-skip-permissions "用understand_image分析图片..."
```

### 方式3：Sonnet官方深度思考（复杂任务）

```bash
# 架构设计、方案规划
claude --print "帮我设计一个XXX系统的完整架构..."
```

## 适用场景

| 任务类型 | 使用模型 | 说明 |
|----------|---------|------|
| 架构设计、方案规划 | 官方Sonnet | 深度思考能力强 |
| 复杂项目开发（多模块） | MiniMax + 本地CC | 便宜、快速 |
| 简单代码修改 | 本地CC | 直接搞定 |
| 图片理解分析 | 本地CC + MCP | 准确率高 |
| Windows桌面程序 | 本地CC | 实际运行测试 |

## 优势

1. **成本低** - MiniMax比官方模型便宜80%+
2. **速度快** - 本地CC无需等待云端排队
3. **跨平台** - Mac开发、Windows测试，互补
4. **可验证** - 本地可以直接运行看效果
5. **Token省** - 主Agent只做调度，不做实际开发

## 示例：开发一个股票监控工具

```
雪子：我想做一个Windows桌面股票监控小工具

主Agent：
1. 官方Sonnet出架构设计
2. 拆解任务：骨架→数据层→UI层→打包
3. 每阶段启动本地CC执行

本地CC：
- Phase 1：创建项目骨架
- Phase 2：实现腾讯API调用
- Phase 3：开发托盘悬浮窗UI
- Phase 4：测试打包exe

主Agent汇总 → 发给雪子 → 完成
```

## 注意事项

1. **大任务用sessions_spawn** - 避免超时
2. **先确认需求再开发** - 避免返工
3. **官方模型做架构** - 复杂项目必须
4. **本地CC测效果** - 实际运行验证
