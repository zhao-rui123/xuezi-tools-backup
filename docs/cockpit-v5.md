# 主控制台 V5 两级导航

*最后更新：2026-05-01*

## 架构
- **一级入口 Hub**：`cockpit-v5-hub.json` — 5个主题按钮 + 二级标题说明（文字，无需点击）
- **二级专题面板**：`cockpit-v5-{key}.json` — 每个主题下的专题按钮

## 5个一级入口
| 入口 | 二级标题 |
|------|----------|
| ⚡ 执行链路 | 执行中心 \| 语义任务面板 \| ACP \| screen详情 \| 重跑测试任务 \| 任务历史 \| 后台任务中心 |
| 📋 任务与记忆 | 任务面板 \| 记忆面板 \| 今日重点 \| 阻塞 \| 高优先级 \| Inbox \| 摘要 |
| 🩺 系统与定时 | 系统面板 \| 定时任务中心 \| 健康检查 \| 备份状态 |
| 🤖 模型与控制 | 模型面板 \| 切换CC模型 \| 会话状态 \| 轻控制入口 \| 清理测试任务 |
| 🔧 快捷 | 快捷动作面板 \| 主控制台 \| 帮助 |

## 关键文件
- `scripts/cockpit_v5_hub.py` — Hub 生成器
- `scripts/cockpit_v5.py` — Hub + Sub 面板生成器
- `summary/cards/cockpit-v5-hub.json` — 主控制台首页
- `summary/cards/cockpit-v5-{key}.json` — 各专题面板

## 无重复设计
- 会话状态 → 只在「🤖模型与控制」
- 重跑测试任务 → 只在「⚡执行链路」
- 清理测试任务 → 在「🤖模型与控制」
