## 三、暂不建议做（避免系统变重）

### 1. 首页继续加状态
- [ ] 不建议再加第三行状态
- [ ] 不建议把 cron / 备份 / 测试结果堆到首页
- [ ] 不建议把首页做成监控大盘

### 2. 横向继续扩入口
- [ ] 不建议继续往一级入口加新栏目
- [ ] 不建议为低频动作单独再开一级主题

### 3. 高风险控制动作直上首页
- [ ] 不建议把停止任务 / 清残留 / 删除类动作直接前置到首页
- [ ] 高风险动作应继续留在专题或确认卡里
