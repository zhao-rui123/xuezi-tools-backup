# 小龙虾之家 AI 助手工作状态看板 - 规格文档

## 1. 项目概述

- **项目名称**: 小龙虾之家 (Lobster Home)
- **项目类型**: 像素风格 AI 助手工作状态可视化看板
- **核心功能**: 通过像素风小龙虾角色在9宫格房子中的移动，展示AI助手的工作状态和统计数据
- **目标用户**: AI 助手用户个人使用

## 2. 视觉与渲染规格

### 像素风设计
- **像素密度**: 8x8 或 16x16 像素网格
- **配色方案**:
  - 主色: #E74C3C (红色小龙虾)
  - 次色: #3498DB (蓝色点缀)
  - 背景: #2C3E50 (深蓝灰)
  - 地板: #95A5A6 (浅灰)
  - 墙壁: #BDC3C7 (白灰)
  - 家具: 各类暖色调
- **渲染风格**: 纯 CSS 像素艺术，无图片依赖

### 9宫格房间布局

```
┌─────┬─────┬─────┐
│ 客厅 │ 工作室 │ 茶水室 │
│(休息)│(代码)│(思考)│
├─────┼─────┼─────┤
│ 厨房 │ 餐厅 │ 游戏室 │
├─────┼─────┼─────┤
│ 卫生间│ 卧室 │ 阳台  │
│      │      │运动场 │
└─────┴─────┴─────┘
```

**房间定义**:
| 房间 | 英文名 | 状态映射 | 像素家具 |
|------|--------|----------|----------|
| 客厅 | Living Room | idle/rest | 沙发 TV |
| 工作室 | Studio | coding/working | 电脑 书架 |
| 茶水室 | Tea Room | thinking | 茶几 茶杯 |
| 厨房 | Kitchen | eating | 灶台 冰箱 |
| 餐厅 | Restaurant | dining | 餐桌 椅子 |
| 游戏室 | Game Room | gaming | 游戏机 |
| 卫生间1 | Bath 1 | grooming | 马桶 洗手台 |
| 卧室 | Bedroom | sleeping | 床 衣柜 |
| 阳台/运动场 | Balcony | exercising | 跑步机 |

### 小龙虾角色设计 (CSS像素画)
- 身体: 红色椭圆
- 钳子: 两个大钳子
- 眼睛: 两个小黑点
- 腿部: 6条细腿
- 状态动画: idle(呼吸), coding(敲键盘), thinking(闪烁), eating(咀嚼)

## 5. 后端 API 规格

### Flask API 端点

| 方法 | 端点 | 描述 |
|------|------|------|
| GET | `/api/status` | 获取当前状态 |
| POST | `/api/status` | 更新状态 |
| GET | `/api/stats/week` | 获取近7天统计 |
| GET | `/api/achievements` | 获取成就列表 |
| POST | `/api/achievements/:id` | 解锁成就 |
| POST | `/api/archive` | 手动触发归档 |
| GET | `/api/stats/today` | 获取今日统计 |

### 数据存储
- 路径: `/opt/lobster-home/data/`
- 主文件: `data.json`
- 归档目录: `archive/`
- 归档命名: `YYYY-MM-DD.json`

### 自动归档
- 触发时间: 每日 00:00 (通过外部定时任务或后端 scheduler)
- 归档内容: 前一天数据移至 archive/

## 7. 部署规格

### 部署路径
- **后端代码**: `/opt/lobster-home/`
- **前端文件**: `/usr/share/nginx/html/my-home/`
- **数据文件**: `/opt/lobster-home/data/`

### Nginx 配置
```nginx
location /api/ {
    proxy_pass http://127.0.0.1:5000/;
}

location / {
    root /usr/share/nginx/html/my-home;
    index index.html;
}
```

### 启动命令
```bash
cd /opt/lobster-home
python app.py &
```
