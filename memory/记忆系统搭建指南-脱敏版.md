## 一、系统架构

```
┌─────────────────────────────────────────────────────────────┐
│                    记忆搜索系统 v3.0                          │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  📝 memory/*.md              ← 每日自动记录 (源)             │
│       ↓                                                       │
│  ┌──────────────────────────────────────────────────────┐    │
│  │  FTS索引 (OpenClaw内置)     │ 中文分词索引 (jieba)    │    │
│  │  - 英文/数字精确匹配        │ - 中文jieba分词         │    │
│  │  - SQLite FTS5            │ - 增量倒排索引          │    │
│  │  - ~2ms                    │ - ~0.6ms               │    │
│  └──────────────────────────────────────────────────────┘    │
│       ↓                        ↓                              │
│       └──────────┬─────────────────┘                            │
│                  ↓                                             │
│           统一索引搜索                                          │
│           (smart-search.py)                                    │
│                                                              │
│  🔄 FTS WAL 变化 → 自动触发中文索引同步                        │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

## 二、核心组件

### 2.1 OpenClaw内置FTS索引

**不需要安装！OpenClaw 4.x内置免费FTS搜索**

| 组件 | 功能 |
|------|------|
| **FTS5** | BM25评分全文搜索 |
| **向量搜索** | 可选，需API Key（不支持MiniMax） |
| **CJK支持** | 英文/数字精确，中文需配合jieba |

**自动触发机制**：
- 文件变化 → dirty标志 → 自动重索引
- 完全后台自动，无需手动干预

**不需要API Key！0 token消耗！**

---

### 2.2 中文分词索引 (jieba)

**核心技术**：Python jieba分词库

| 特性 | 说明 |
|------|------|
| **分词方式** | 整句匹配 + 关键词提取 |
| **索引类型** | 倒排索引 |
| **更新方式** | 增量（mtime检查） |
| **触发机制** | FTS WAL变化时自动同步 |
| **搜索速度** | ~0.6ms |

**优势**：
- 中文搜索比原生FTS更准
- 整句匹配不怕分词碎片化
- 本地运行，无需API

---

### 2.3 统一索引 (unified_index)

**整合FTS + 中文索引，一次搜索全覆盖**

| 搜索类型 | 引擎 | 速度 |
|----------|------|------|
| 中文 | jieba分词 | ~0.6ms |
| 英文/数字 | FTS | ~0.8ms |
| 混合 | 两者合并 | ~1.3ms |

**结果标记**：
- `✅ both` = 双重命中
- `📦 fts` = 仅FTS匹配
- `🇨🇳 cn` = 仅中文匹配

### 3.4 创建 launchd 监听器（macOS）

```bash
# 创建监听脚本
cat > ~/.openclaw/ops/bin/memory-file-watcher.sh << 'EOF'
#!/bin/bash
# FTS索引监听器 - 监控FTS SQLite的WAL文件，FTS更新时触发中文索引同步
python3 << 'PYTHON'
from watchdog.observers import Observer
from watchdog.events import FileSystemEventHandler
import subprocess, time, os
from pathlib import Path

FTS_DIR = Path.home() / ".openclaw" / "memory"
MEMORY_SUITE_DIR = Path.home() / ".openclaw/workspace/skills/memory-suite-v4"

class FTSWatcherHandler(FileSystemEventHandler):
    def __init__(self):
        self.last_update = 0
        self.cooldown = 3
        
    def on_any_event(self, event):
        if event.is_directory:
            return
        src = event.src_path
        if 'claude.sqlite' in src or src.endswith(('.wal', '-shm', '.md')):
            self._trigger_sync()
    
    def _trigger_sync(self):
        now = time.time()
        if now - self.last_update < self.cooldown:
            return
        self.last_update = now
        # 调用中文索引同步
        subprocess.run(['python3', '-c', f'''
import sys
sys.path.insert(0, "{MEMORY_SUITE_DIR}")
from core.chinese_indexer import ChineseIndexer
indexer = ChineseIndexer()
indexer.update_index()
'''], capture_output=True)

if __name__ == "__main__":
    observer = Observer()
    observer.schedule(FTSWatcherHandler(), str(FTS_DIR), recursive=True)
    observer.start()
    try:
        while True: time.sleep(1)
    except KeyboardInterrupt:
        observer.stop()
    observer.join()
PYTHON
EOF

chmod +x ~/.openclaw/ops/bin/memory-file-watcher.sh

# 创建launchd服务
cat > ~/Library/LaunchAgents/com.xuezi.memory-watcher.plist << 'EOF'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.xuezi.memory-watcher</string>
    <key>ProgramArguments</key>
    <array>
        <string>/bin/bash</string>
        <string>/Users/zhao/.openclaw/ops/bin/memory-file-watcher.sh</string>
    </array>
    <key>RunAtLoad</key>
    <true/>
    <key>KeepAlive</key>
    <true/>
</dict>
</plist>
EOF

launchctl load ~/Library/LaunchAgents/com.xuezi.memory-watcher.plist
```

## 四、使用流程

### 4.1 日常搜索

```bash
# 统一搜索（自动判断中英文）
cd ~/.openclaw/workspace/skills/memory-suite-v4
python3 cli.py search-unified "关键词"

# 中文精确搜索
python3 cli.py search-cn "中文关键词"

# 英文/数字搜索
openclaw memory search "关键词"
```

### 4.2 混合搜索示例

```bash
# 中文+英文混合
python3 cli.py search-unified "韩国服务器 acpx" --all
```

### 4.3 索引状态检查

```bash
# 查看FTS状态
openclaw memory status

# 查看中文索引状态
cd ~/.openclaw/workspace/skills/memory-suite-v4
python3 cli.py status
```

### 4.4 手动重建索引

```bash
# 重建中文索引
cd ~/.openclaw/workspace/skills/memory-suite-v4
python3 cli.py build-cn-index --force
python3 cli.py build-unified-index --force

# 重建FTS索引
openclaw memory index --force
```
