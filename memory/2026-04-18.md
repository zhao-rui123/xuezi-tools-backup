## 🔧 系统问题修复

### OpenClaw Gateway 内存泄漏问题
- **根因**: OpenClaw session 累积了 120 个，只有 warn 模式不清理
- **修复**: 配置 session maintenance
  ```json
  "session": {
    "maintenance": {
      "mode": "enforce",
      "pruneAfter": "3d",
      "maxEntries": 30
    }
  }
  ```
- **效果**: 内存 970MB → 490MB，session 120 → 30
