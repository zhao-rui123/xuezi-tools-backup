

## 2026-05-01 主控制台 V5 完整收口（23:00后）

### 最终架构：两级导航
- **主控制台 V5 Hub**：5个一级入口，每个入口下有二级标题说明（文字，无需点击）
- 一级入口：⚡执行链路 / 📋任务与记忆 / 🩺系统与定时 / 🤖模型与控制 / 🔧快捷
- 二级标题：每个入口下的专题清单，用户点之前就知道里面有什么

### 关键文件
- `scripts/cockpit_v5.py` — 生成两级导航面板（hub + sub）
- `scripts/cockpit_v5_hub.py` — 生成带二级标题的 Hub 首页
- `summary/cards/cockpit-v5-hub.json` — 主控制台 V5 首页
- `summary/cards/cockpit-v5-{key}.json` — 各专题二级面板

### 重跑测试任务 V3 完整链路
1. 候选面板（rerun-test-tasks-panel-card）
2. 确认卡（rerun-confirm-{task}.json）→ 按钮触发 `rerun execute {task}`
3. 命令处理器（handle_rerun_cmd.py）→ 调用 rerun-test-task.sh → rerun-test-task-result.sh
4. 结果卡（rerun_result_card.py）→ 发回飞书

### 飞书卡片限制
- 完整主控制台卡片约 11KB，飞书限制约 4KB/条
- 解决方案：主控制台发精简版（V5 hub），各专题发独立卡片
- 卡片内文字用空格代替换行，避免字符超限
