## 🎨 图片生成（双链路）

### 链路1：`image_generate` 工具（OpenClaw 内置）
**底层**: GPT Image 2（通过 openai-codex-image 插件接入）
**配置**: `imageGenerationModel.primary = openai-codex/gpt-image-2`

使用方式：直接调用 `image_generate` 工具即可。

### 链路2：MiniMax image-01 API
**API**: `https://api.minimaxi.com/v1/image_generation`
**认证**: Bearer Token（Token Plan Key）

```bash
curl -X POST "https://api.minimaxi.com/v1/image_generation" \
  -H "Authorization: Bearer <Key>" \
  -H "Content-Type: application/json" \
  -d '{"model":"image-01","prompt":"描述","aspect_ratio":"16:9","response_format":"url","n":1}'
```

图生图（subject_reference）：
```python
requests.post(
    "https://api.minimaxi.com/v1/image_generation",
    headers={"Authorization": "Bearer <Key>"},
    json={
        "model": "image-01",
        "prompt": "场景描述",
        "subject_reference": [{"type": "character", "image_file": f"data:image/jpeg;base64,{img_base64}"}]
    }
)
```

**限制**：只支持单张照片参考，base64 需小于 10MB。

**也可用**：`mmx image generate "描述"`

## 🔍 流式卡片问题排查结论

### 问题描述
feinian/gpt-5.4 切换后，流式卡片消失

### 排查结果
- 配置 streaming=true 是开的
- Feishu 历史有 streaming start failed 400 错误
- feinian 链路出现 stream_read_error
- MiniMax 有流式卡片体验

### 结论
**不是 Feishu 整体坏了，是 feinian 这条 openai-responses provider 链路基本不支持流式卡片体验**

### 补偿方案
用静态卡片化展示替代流式卡片，保持长内容可读性
