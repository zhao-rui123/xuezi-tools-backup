## 🧠 MindVault 项目结构

```
mindvault/
├── core/              # 核心模块
│   ├── real_time.py  # 实时快照
│   ├── archiver.py   # 归档管理
│   ├── indexer.py    # 语义索引
│   ├── analyzer.py    # 记忆分析
│   └── distiller.py  # ⭐ 每日提纯（L0→L1）
├── knowledge/         # 本地知识库
│   ├── knowledge_manager.py
│   ├── knowledge_graph.py
│   └── knowledge_search.py
├── apps/
│   └── evolution/     # 用户画像
└── cli.py            # 统一命令入口
```

## 📊 核心功能

| 功能 | 说明 |
|------|------|
| 实时快照 | 每10分钟保存会话 |
| **每日提纯** | 全量对话→长期记忆 |
| 本地知识库 | 知识图谱+语义搜索 |
| 用户画像 | 偏好分析 |
