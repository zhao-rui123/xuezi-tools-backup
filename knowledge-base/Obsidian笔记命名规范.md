# Obsidian笔记命名规范 v4.0

*更新: 2026-04-07*

## 核心原则

1. **日期优先** - 一眼看出时间
2. **领域明确** - 一眼看出领域
3. **层级清晰** - 标签体现结构
4. **简洁可读** - 不过长，有意义

---

## 文件命名格式

### 标准格式
```
YYYY.MM.DD-领域-主题.md
```

### 示例
```
2026.04.06-AI-MindVault开源项目.md
2026.03.15-储能-亦庄项目IRR测算.md
2026.03.20-股票-比亚迪分析.md
2026.04.06-工作-周报.md
```

## 标签命名规则

1. **全小写** - #储能/irr（不是#储能/IRR）
2. **用 `/` 分层** - 最多2层，特殊情况3层
3. **直观易懂** - 看到就知道是什么
4. **避免特殊字符** - 不要有空格、 emoji

---

## AI工作流

1. **写新笔记** → 按格式命名 → 打标签
2. **搜索** → 先想领域（一级） → 再想类型（二级）
3. **整理** → 每月归档旧笔记 → 保持活跃笔记精简
