# Obsidian笔记命名规范 v2.0

*创建于2026-04-05*

## 核心原则

1. **日期优先** - 一眼看出时间
2. **领域明确** - 一眼看出领域
3. **简洁可读** - 不过长，有意义

---

## 文件命名格式

### 项目文件
```
YYYY.MM.DD-领域-项目名称.md
```

### 知识文件
```
YYYY.MM.DD-领域-知识主题.md
```

### 决策存档
```
YYYY.MM.DD-决策-决策主题.md
```

### 工作记录
```
YYYY.MM.DD-工作日志.md
```

## 标签系统

### 领域标签
```
#储能 #股票 #财务 #电气 #零碳园区
```

### 类型标签
```
#项目 #知识 #决策 #模板 #待办
```

### 状态标签
```
#进行中 #已完成 #待回顾 #重要
```

### 组合示例
```
#储能 #项目 #亦庄 #进行中
#股票 #赣锋锂业 #技术分析
#决策 #2026-Q2 #重要
```

## 目录结构

```
雪子助手/
├── README.md              # 入口
├── 命名规范.md            # 本文档
├── 模板.md                # 快速创建模板
├── 技能索引/             # 技能包说明
│   ├── 我的技能.md
│   ├── 股票分析系统.md
│   └── ...

├── 雪子档案/             # 雪子信息
└── 工作/                 # 每日日志
    └── YYYY.MM.DD-工作日志.md

notes/                    # PARA知识库
├── projects/             # 项目
├── areas/                # 领域
├── resources/            # 资源
└── archive/              # 归档
```

## 维护原则

1. **每日记录** - 工作日志当天记
2. **项目及时更新** - 进展随时记
3. **决策必存档** - 重要决策马上记
4. **定期回顾** - 每周整理一次
