## 项目概述

**目标**: 开发一个储能领域专业Agent，融合雪子的项目经验，大幅提升储能项目评估和方案设计效率。

**核心价值**: 
- 把雪子的储能项目经验变成可复用的AI能力
- 减少重复性工作，专注核心判断和决策
- 知识沉淀，不随人员变动丢失

## Agent能力规划

### 基础能力
| 能力 | 输入 | 输出 |
|------|------|------|
| 项目评估 | 土地面积、用电量 | 初步方案 |
| IRR测算 | 电价、项目规模 | IRR、回收期 |
| 方案建议 | 基本参数 | 电池容量、逆变器配置 |

### 进阶能力
| 能力 | 说明 |
|------|------|
| 方案比选 | 多方案优劣分析 |
| 风险评估 | 项目风险识别 |
| 报价建议 | 参考报价范围 |
